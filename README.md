# Ledger. — Expense Tracker

## About the Project

Ledger. is a personal expense tracker website designed to help users organise and monitor their spending. The project features a clean, minimalist dashboard with a warm, neutral colour palette and a simple layout for entering expenses and viewing spending summaries.

The application is being developed with HTML and CSS, with JavaScript functionality planned for expense management, spending calculations, category filtering, and currency conversion.

## Current Features

- **Expense Entry Form:** A form for entering an expense description, amount, currency, and category.
- **Spending Summary:** A dashboard section designed to display the total amount spent.
- **Home Currency Selection:** A dropdown intended to let users select their preferred currency for viewing total spending.
- **Expense List:** A section designed to display recorded expenses.
- **Category Filtering:** A dropdown intended to filter expenses by category.
- **Responsive Layout:** CSS media queries intended to adapt the interface to different screen sizes.
- **Minimalist Design:** A neutral colour palette, styled form controls, and a clean dashboard layout.

*Note: These features describe the current interface and intended functionality. The interactive features are not yet functional because the JavaScript implementation is incomplete.*

## Technologies Used

- **HTML5** — Structures the website and its content.
- **CSS3** — Styles the interface, including layout, colours, typography, and responsive design.
- **Google Fonts** — Provides web typography.
- **JavaScript (planned)** — Will be used to implement interactive features and application logic.

## Getting Started

### Prerequisites

You need a modern web browser like Chrome and a code editor to view or modify the project.

### Installation

1. Clone the repository:

   ```bash
   git clone git@github.com:im-jaz/Ledger.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ledger
   ```

3. Open `index.html` in your web browser, or use the Live Server extension in Visual Studio Code to preview the website locally.

## Current Development Status

Ledger. is currently in the initial development stage.

The HTML structure and CSS styling establish the foundation of the application. JavaScript has not yet been implemented, so the expense form, spending calculations, category filtering, and currency conversion are not operational.

Planned functionality includes:

- Adding and displaying expenses dynamically.
- Validating expense descriptions and amounts.
- Calculating total spending.
- Deleting individual expenses.
- Filtering expenses by category.
- Converting expenses into a selected home currency using exchange rates.
- Displaying appropriate loading and error messages for exchange-rate requests.

## Future Improvements

- Implement JavaScript functionality for expense management.
- Integrate an exchange-rate API for currency conversion.
- Add persistent storage so expenses remain available after refreshing the page.
- Improve accessibility and responsiveness across different devices.
- Add expense editing and additional spending summaries.
